# 고양이가 인간을 키움 (프로토타입)

실행: 이 폴더에서 `python -m http.server 8000` (또는 `npx serve`) 을 실행하고 브라우저로 `http://localhost:8000` 을 연다. 디버그 메뉴는 주소 뒤에 `?debug=1`.

- 개발 명세: `SPEC.md`
- 기획서·밸런스 엑셀: `docs/`
- 밸런스 숫자: `src/config.js` (엑셀 '설정값' 시트와 같은 값)
- 배포: Netlify가 이 브랜치를 자동 배포. `_redirects`가 `docs/`와 문서 파일을 사이트에서 막는다.
